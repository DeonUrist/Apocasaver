Apocasaver 2.0.2 restores the intended save policy: saving is not rejected because an optional feature or a completeness
check is uncertain. Missing native confirmations, unexpected FSM states, companion compatibility problems and cleanup
uncertainty are log warnings. Prior useful records are retained; uncertain cleanup is skipped.

When rebuilding cannot initialize, the game saves normally without deleting the destination. If a completion confirmation
is missing, available save data is written instead of being rejected after 60 seconds. Actual disk persistence failures
still restore the previous save from backup and show a failure warning.

CleanSaves remains off by default and includes abandoned Apocapatrol vehicles/items when supported. A candidate that becomes
protected during saving is kept in both the game world and the saved registration arrays.

Includes the 2.0.1 destroyed-plugin-component startup fix. Update Apocasaver and restart the game; no companion update is
required for the installed versions tested. Full interactive/long-session validation remains pending.
