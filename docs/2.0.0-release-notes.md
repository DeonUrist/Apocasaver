Saving repeatedly in one slot can retain obsolete object and vehicle-position records. Apocasaver 2.0.0 rebuilds supported manual saves and autosaves from a fresh cache while carrying useful history from the current playthrough into both occupied and empty slots.

- Back up occupied slots before replacement, verify the saved records, and restore the previous save and slot label on failure. Persistent recovery journals also cover interrupted saves; three successful pre-save backups are retained per slot.
- Preserve location spawn, visited and resource state, including sites that unload or are reused by terrain generation. Keep opaque mod data and avoid importing the destination slot's previous world.
- Save vehicle-hinge rotations under stable reference keys to prevent movement from accumulating old position records.
- Add **CleanSaves**, **off by default**. When enabled, remove audited disposable remains/packs and, with Apocapatrol loaded, abandoned unclaimed patrol vehicles, crew, cargo, parts and generated detached items over 1 km away for 10 minutes. Protect owned, handled, stored, merchant/unique and referenced objects. Objects are destroyed only after successful save verification.
- Coordinate Apocapatrol 2.7.0 sidecars and Apocapocket 2.0.7 inventory mappings. Preserve file-only ES3 writes and cancel delayed writes after a failed save.

**Install:** exit the game and extract the ZIP into the game directory, replacing `BepInEx/plugins/Apocasaver.dll`. Companion mods do not need replacement. To enable optional cleanup, set `[Saving] CleanSaves = true` in `BepInEx/config/com.denis.apocalypter.apocasaver.cfg` after launching the upgraded mod once.

**Validation:** Release build with zero warnings/errors; 91 automated checks; 27 native Unity fixture checks without companion mods and 36 with them. Full interactive and long-session gameplay validation remains pending. See the included verification report for the test scope and remaining limits.
