# Apocasaver 2.0.3

Successful manual saves show "Game saved" even when optional diagnostics were logged. Temporary autosave deferrals remain in the log. Disk-write failures and backup recovery still produce on-screen notices; the autosave countdown and first-save reminder remain.

Fixes save-time PlayMaker warning spam caused by inspecting actions on uninitialized load-menu FSMs during CleanSaves. Those actions are left untouched; unknown external references still protect cleanup candidates.

Write-confirmation diagnostics now match native event eligibility: inactive visual vehicle parts, disabled components and finished FSMs do not need to write. Prior useful records are retained. An active object's missing write remains a warning; disk failures retain the existing rollback behavior.

The other player's log included a turbo and wheel with unconfirmed writes. Their exact runtime hierarchy is unavailable, so these fixes cover the demonstrated code defects without claiming to have replayed that player's session. Missing DustStorm compatibility lookups, duplicate Rigidbody messages and Mods-window click diagnostics come from other paths and are not suppressed by this update.

Companion inventory fixes are packaged separately as Apocapocket 2.0.8.
