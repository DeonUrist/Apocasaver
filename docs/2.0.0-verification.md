## Remaining practical limits

These are native fixtures, not an interactive menu replay or a long driving session. They do not establish performance or
every terrain pooling/initialization ordering under gameplay load. The pocket fixture tests an empty mapping, not a complete
six-slot gameplay inventory. A full playthrough should confirm native menu artwork, reload/revisit behavior, multi-vehicle
prefab reference restoration and loaded pocket contents. No fixed save-size or frame-rate improvement is claimed.

Unknown legacy/mod records are retained conservatively. Cleanup uses a narrow audited vanilla category set; it does not
remove all corpses or empty containers. Patrol cleanup deliberately permits abandoned unclaimed mod-generated items, while
handled/stored/owned, merchant/unique or externally referenced objects remain protected.

The default rebuild preserves meaningful history, so it may be larger than a vanilla fresh-slot save that omitted that
history. Repeated obsolete hinge keys and confirmed obsolete native object records are eliminated without deleting live
objects unless CleanSaves is enabled.
